# MathMerit / 数学品评

[English](README.md)

## 为什么需要这个项目

**让英雄查英雄，好汉查好汉。**

随着 AI4Math 急速发展，论文越来越多：哪些值得数学家花时间阅读？本项目从第一性原理出发，探索并倡议一种数学成果贡献评价方法，同时提供自动化技能，帮助数学家筛选值得一看的文章。

## 第一性原理

> **数学成果服务于数学共同体对数学对象、结构与问题的认识。**

## 评价方法

[Copernicus](Copernicus.zh.md) 是供数学共同体采用、讨论与修订的方法正文：从基本倡议出发，提出五项评价、各项等级和五维评价图。等级与图示都是方法的一部分，可用于人的评价，也可由 AI 辅助实现。另有[英文版](Copernicus.en.md)。

| 方面 | 评判短句 |
|---|---|
| 知识 | 确立了什么，增强了什么根据？ |
| 理解 | 澄清了什么问题，揭示了什么关系或机制？ |
| 方法 | 哪些任务变得可做，哪些代价得到降低？ |
| 表达 | 消除了哪些理解、核查与使用的障碍？ |
| 意义 | 这些改善为什么值得重视？ |

五维图以各项文字等级呈现贡献的不同方面；等级不相加，面积不表示总体价值。贡献凭根据，意义由人判断，长远影响待历史检验。

## 自动化技能

[MathMerit](SKILL.md) 是这套方法的自动化实现。向 AI 助手提供数学文本或相互依赖的系列工作，并明确版本，即可按[执行规则](references/profile-format.md)生成有根据的评价、五维图及阅读建议。

使用助手支持的本地技能安装方式，将本目录安装为 `mathmerit`。英文方法、执行规则与图模板可独立支持英文使用，无须读取中文版或另装语言包。输出采用用户指定的语言，未指定时跟随请求语言；需要双语时明确提出即可。

例如：“用 $mathmerit 评价这篇论文，以中文输出。”
