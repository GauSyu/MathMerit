# MathMerit / 数学品评

[English](README.md)

## 为什么需要这个项目

**让英雄查英雄，好汉查好汉。**

随着 AI4Math 急速发展，论文越来越多：哪些值得数学家花时间阅读？本仓库包含两个目标不同的部分：

- **Copernicus——面向数学共同体的倡议。** 从第一性原理出发，探索并倡议一种数学成果贡献评价方法。
- **MathMerit——帮助数学家筛选文章的 AI 技能。** 参考 Copernicus 的判据，帮助数学家选择值得一看的工作，并明确 AI 判断的局限。

Copernicus 可供人类独立采用；MathMerit 使用其中的判据。两者在同一仓库维护，以保持方法与技能一致，各自的目的与产物明确区分。

## 第一性原理

> **数学成果服务于数学共同体对数学对象、结构与问题的认识。**

## Copernicus：评价倡议

[Copernicus](Copernicus.zh.md) 是供数学共同体采用、讨论与修订的方法正文：从基本倡议出发，提出五项评价、各项等级和五维评价图。等级与图示都是方法的一部分，可用于人的评价，也可由 AI 辅助实现。另有[英文版](Copernicus.en.md)。

| 方面 | 评判短句 |
|---|---|
| 知识 | 确立了什么，增强了什么根据？ |
| 理解 | 澄清了什么问题，揭示了什么关系或机制？ |
| 方法 | 哪些任务变得可做，哪些代价得到降低？ |
| 表达 | 消除了哪些理解、核查与使用的障碍？ |
| 意义 | 这些改善为什么值得重视？ |

五维图以各项文字等级呈现贡献的不同方面；等级不相加，面积不表示总体价值。贡献凭根据，意义由人判断，长远影响待历史检验。

## MathMerit：AI 技能

[MathMerit](SKILL.md) 为人类数学家生成筛选报告：推测的五维等级及具体理由、五轴图、AI 判断的局限、推荐与不推荐理由，以及综合阅读等级。报告署明所用模型，并引用本仓库。报告仅帮助数学家筛选值得一看的工作；五维等级是服务于阅读取舍的 AI 推测，不应作为对数学工作质量的评定。详见[报告与推荐规则](references/profile-format.md)。

使用助手支持的本地技能安装方式，将本目录安装为 `mathmerit`。英文方法、执行规则与图模板可独立支持英文使用，无须读取中文版或另装语言包。输出采用用户指定的语言，未指定时跟随请求语言；需要双语时明确提出即可。

例如：“用 $mathmerit 帮我判断这篇论文是否值得阅读，以中文输出筛选报告。”
